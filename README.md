# More-Effects-in-Potions
A Minecraft mod adds more potions with vanilla effects that can't be crafted 

This is the **Fabric 1.20.1 version for this mod**, but this version wasn't coded with IDE, it uses [MCreator ](https://mcreator.net/) with **Fabric 1.20.1 Generator** (Not exists now on MCreator's plugin site), but you can [Download here to access and fork this project](https://github.com/Goldorion/Fabric-Generator-MCreator/releases?page=2#release-1.20.1-1.10) (require MCreator 2023.4)

**Requirement**:

- [Fabric 1.20.1 Generator](https://github.com/Goldorion/Fabric-Generator-MCreator/releases?page=2#release-1.20.1-1.10)

- [MCreator 2023.4](https://mcreator.net/download/2023-4)
